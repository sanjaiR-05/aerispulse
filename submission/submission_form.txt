7. PROBLEM STATEMENT & BACKGROUND:
Metropolitan centers across India (Delhi NCR, Mumbai, Bengaluru, Chennai) suffer severe episodic atmospheric toxic spikes (PM2.5, PM10, NO2, SO2, CO, O3) exceeding WHO thresholds by up to 15x. Existing public applications display passive, unverified numerical indices without calculating real human inhaled physiological dosage, lack personal mitigation protocols, fail during upstream LLM outages, and exclude non-English speakers.

8. SOLUTION OVERVIEW:
AerisPulse delivers a production-grade full-stack intelligence system combining:
- Live ground-truth CAMS atmospheric telemetry from Open-Meteo with multi-station synthetic verification.
- Peer-reviewed mathematical calculation engines (WHO AQG 2021, US EPA 454/B-18-007, PNAS GEMM 2018, DEFRA 2023) enforcing deterministic separation: "The LLM explains; code calculates."
- Interactive What-If lifestyle simulator computing daily inhaled PM2.5 dosage (µg/day), carbon abated (kg CO2/day), monthly health savings (₹/mo), and Personal Health Shield Score (0-100).
- Structured GenAI Action Engine (Google Gemini with JSON schema enforcement) with candidate failover and an offline deterministic rules engine (fallback-service.ts) for 100% zero-downtime availability.
- Server-Sent Events (SSE) streaming chat grounded in verified telemetry with XML boundary isolation against prompt injections.
- Trilingual localization (English, Tamil, Hindi) and 100% WCAG 2.2 AA accessibility compliance (0 axe violations).

9. ARCHITECTURE & TECH STACK:
- Framework: Next.js 15 (App Router) + React 19 + Tailwind CSS + TypeScript (strict mode, zero any).
